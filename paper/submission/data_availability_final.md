# Data availability

N-CMAPSS is publicly available through NASA's [Prognostics Center of Excellence Data Set Repository](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/), entry 17, “Turbofan Engine Degradation Simulation-2.” This study used DS02 and DS03. The raw NASA dataset files are not redistributed in this repository. NASA and the dataset contributors retain the source attribution; the author does not claim ownership of the data.
