# Literature positioning audit for Introduction and Related Work

This file records claim boundaries, not manuscript results. The numbered links are primary papers or original dataset/method publications used in `introduction.md` and `related_work.md`. The gap is an inference from these representative works, not a claim that an exhaustive systematic review found no prior phase-calibration audit.

## Five closest papers a skeptical reviewer may cite

1. [9] Yan *et al.* (2026), “A Physics-Guided Spatio-Temporal Attention Graph Network for Unsupervised Aircraft Engine Anomaly Detection.” It uses N-CMAPSS and compares PCA, autoencoder, LSTM-autoencoder, and temporal models. Distinction: its main comparisons are detector-performance metrics, not a frozen pooled-threshold phase-FPR audit.
2. [6] Zhao *et al.* (2022), “Research on an Adaptive Threshold Setting Method for Aero-Engine Fault Detection Based on KDE-EWMA.” It explicitly divides the flight envelope and sets context-sensitive thresholds. Distinction: adaptive threshold design is prior art; this paper tests the stability of a fixed nominal pooled calibration under complete-flight evaluation.
3. [2] Borguet *et al.* (2011), “Assessment of an Anomaly Detector for Jet Engine Health Monitoring.” It explicitly uses a prescribed false-alarm probability and evaluates detection decisions. Distinction: the present endpoint is phase-conditional healthy FPR and cross-phase transfer under one frozen protocol.
4. [7] Ulmer *et al.* (2024), “A Generic Machine Learning Framework for Fully-Unsupervised Anomaly Detection with Contaminated Data.” It uses N-CMAPSS DS02 and residual/PCA-style anomaly modelling. Distinction: its target is contaminated-training-data refinement and detection, not calibration stability across flight phases.
5. [10] Cheng and Miao (2026), “CruiseBench: A Real-Flight-Aligned N-CMAPSS Benchmark for Engine RUL Prediction.” It identifies flight-stage variation and constructs a cruise-stage benchmark. Distinction: it isolates a phase for prognostic comparability, whereas this paper audits healthy false alarms across phases.
